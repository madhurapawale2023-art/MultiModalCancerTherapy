# MultiModalCancerTherapy

Simple professional AngularJS + FastAPI + PostgreSQL + Jupyter architecture.

This first package is **structure only**. Coding comes after the structure is confirmed.

Core workflow:
Patient Registration -> Multimodal Data -> AI Engine -> Assistant Doctors -> Senior Doctor Review -> Final Treatment Plan

Included modalities:
Clinical, Laboratory, Pathology, Ultrasound, CT/MRI, Molecular (non-DNA)

Genetic DNA testing is intentionally excluded from this project.
